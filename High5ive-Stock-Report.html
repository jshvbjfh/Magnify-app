2. Root Cause Analysis

There are two distinct problems. They appear similar (stock = zero) but require different fixes.

2.1 — Kitchen Branches: Stock Was Never Loaded

All four kitchen branches have correct, detailed recipes in the system. Each dish is linked to the right inventory items with the right quantities in grams, millilitres, or pieces. The problem is that no stock quantities have ever been successfully entered for those items.

An earlier attempt was made to load stock from a physical stocktake sheet. The attempt failed for most items due to two specific issues:

Issue A — Unit Mismatch (KG on the sheet vs grams in the system)

The physical stocktake sheet recorded items like "Beef 3 KG", while the recipes (correctly) use grams. The system stores stock in the same unit as the recipe — so "Beef" stock must be entered in grams. Items recorded in KG need to be multiplied by 1,000 when entered.

Example: "Beef 3 KG" → enter 3,000 g in the system.

Issue B — PCS Items: Quantity per Piece Unknown

The stocktake sheet recorded items like "Chicken PCS 20" (meaning 20 whole chickens or 20 chicken pieces). But the recipes require chicken in grams (e.g. "Chicken breast 120 g per dish"). Without knowing how many grams each piece weighs, the system cannot know how many dishes that stock covers.

Key question for the manager: For each "PCS" item on the physical stock sheet — how many grams is one piece? For example: one chicken breast ≈ 200g, one pork chop ≈ 180g, one beef portion ≈ 150g. Once confirmed, we multiply: 20 chicken pieces × 200g = 4,000g to enter.

Issue C — Name Mismatch

The stock sheet sometimes uses different names than the system. For example, the sheet may say "Beef" while the system has three separate items: "Ground beef", "Beef (strips)", "Beef (braised chunks)", and "Beef filet" — each used by a different dish. A name mapping must be agreed before stock can be loaded accurately.

2.2 — Bar Branches: No Recipes Built

Both Banana Bar and Parking Bar have no ingredient recipes at all. This means stock consumption cannot be tracked for any cocktail or drink. This is a deliberate decision that was made when those menus were built — cocktails were set up as simple items without ingredient links.

Decision needed: Does the manager want cocktail ingredients tracked? For example, if "Bisoke Mojito" (15,000 RWF) uses 40ml rum, 20ml lime juice, mint, sugar — those ingredients can be added as recipes and stock-tracked. This requires building a recipe for each of the 58 bar items.

5. Recommended Action Plan

The following steps are recommended in order of priority:

  • Manager provides physical stocktake sheet — A complete list of current quantities for all kitchen branches, with units (KG or PCS or L). This is the only thing blocking stock from being loaded.
  • Agree gram-per-piece for PCS protein items — Confirm how many grams one chicken breast, one beef fillet, one pork chop, etc. weighs on average in the High 5ive kitchen. This converts the "20 PCS chicken" on the sheet to "4,000 g" in the system.
  • Load stock for THE GRILL — Smallest branch (8 dishes, ~10 inventory items). Start here to test the workflow and confirm numbers are right before touching larger branches.
  • Load stock for Tiamo Pasta — 6 dishes, straightforward items (pasta, canned tomatoes, cream, cheese). Easy to verify against what the kitchen can physically count.
  • Load stock for WHATABURGER — DONE (9 Jul 2026) Core proteins, buns, cheese, and potato are stocked. Remaining: lettuce leaf, burger sauce, jalapeños, and sour cream/sauce still need a physical count + cost.
  • Load stock for Little Taipei — Largest kitchen branch (16 dishes, ~50 inventory items). More complex but all recipes are already set up correctly.
  • Decision: bar tracking — After kitchen branches are live, decide whether to build recipes and track stock for Banana Bar and Parking Bar. This is optional but recommended for full cost control.
  • Set up reorder alerts — Once stock is loaded, configure low-stock thresholds for critical items (proteins, key sauces) so the kitchen gets a warning before running out.
